01 / The Concept

Why Role & Risk-Based Access?

Instead of static passwords, RBA uses identity verification and real-time security grading to stop intruders and bot attacks.

🎯

Least Privilege

Users receive only the access needed to perform their responsibilities, limiting unnecessary exposure.

🧩

Risk-Based Grading

Assigns a real-time trust score out of 100 based on failed attempts and network behavior.

📊

Better Auditing

Tracks repeated wrong OTP attempts and automatically blocks suspicious sessions.

02 / Architecture

How RBA Works

A simple verification flow from identity to trust score.

01 · USER REQUESTUser enters registered Gmail address.
02 · OTP DISPATCHBackend generates a 4-digit code and calculates starting trust score (100).
03 · RISK SCORINGDeducts 25 points on every incorrect guess or IP change.
04 · VERIFICATION DECISIONGrants access if score ≥ 50, otherwise flags and blocks access.

Security Principles

✓ Direct Gmail OTP Verification
✓ Dynamic 0–100 Trust Score Evaluation
✓ 3-Strike Automatic Lockout
✓ Prevents brute-force credential stuffing
